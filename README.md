# SVVAYAM — Interactive Sales Presentation

A guided, non-linear presentation website for **Svvayam** (Additive Manufacturing Infra Development Pvt Ltd) — bespoke luxury pooja rooms and sacred architectural sanctuaries.

## Features
- **Brand Presentation Landing Page** with official logo and ambient glow.
- **Top Navigation Flow** with `<` Back / `>` Forward history tracking.
- **Client Explorer (Size x Detail)** with animated glowing white & gold light beams.
- **Curated Projects Gallery** with material/typology filters.
- **10-Stage Sales Workflow**: Overview, Requirements, Concept, 2D CAD, 3D Model, Detailing, Manufacturing, Transport, Installation, Final.

## How to Run
Open `index.html` in any web browser.
